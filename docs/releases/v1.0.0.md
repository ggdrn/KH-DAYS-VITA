# 1.0.0 — Release

Release 1.0 with OFF, SIMPLE and DETAIL single-screen modes.

## Changes

- Fixed the post-credits save-scene descriptor and restored the cleared-game save flow, Theater Mode and Zero Gear unlock path.
- Added linked-ELF validation and diagnostic logging for the ending save scene.
- Fixed the mostly black display that could occur after pausing and resuming the final Riku battle.
- Fixed the brief widescreen 4:3 HUD corruption when opening the L shortcut.
- Fixed the temporary stretched Darkside tentacle geometry in Holo-Mission: Two Keys.
- Extended the pause dim overlay across the widescreen side borders, including cutscene menus with Continue / Skip.
- Added three single-screen choices: OFF, SIMPLE and DETAIL.
- SIMPLE uses static panels with fewer 2D texture effects and filters for better performance.
- DETAIL keeps richer HUD composition, detailed 2D filtering and effects for a more immersive experience at a higher rendering cost.
- Added mode-change logging and optimized DETAIL by skipping smoothing for pixels discarded by HUD masks.
- The Vita requests CPU 444 MHz, GPU 222 MHz, bus 222 MHz and XBAR 166 MHz. No unsafe forced-100% utilization mode was added.

## Performance findings

The supplied performance log contains menu transitions, scene changes and different layouts, so it does not provide a controlled OFF/SIMPLE/DETAIL comparison. CPU percentages are thread-group measurements, not total hardware utilization, and GPU completion time is not a direct utilization percentage.

The existing port already requests the configured maximum clocks. Increasing thread activity to 100% would not guarantee more frames and could harm audio and synchronization. The log now records the effective clocks for verification.

## Validation

- Native Vita build completed successfully.
- Post-link ending-scene check passed.
- Composition, ending-link and GX3D host tests passed.
- The VPK archive passed integrity validation.
- Real Vita testing is still required for performance and the cutscene Continue / Skip overlay.

## Test procedure

Use the same mission, resolution, HUD and filter settings. Warm the DETAIL shader cache once, then test OFF, SIMPLE and DETAIL for at least 20 seconds each with the menu closed. Repeat with debug logging disabled. During a cutscene, test Continue and Skip in all three modes and confirm that the side borders dim and return to normal after closing the pause menu.
