# 1.2.1 — Release

Version 1.2.1 fixes the Mission 79 hang in Halloween Town and lets the port run modified copies of the European cartridge, such as an undub with the Japanese voices and cutscenes.

## Highlights

- Fixed Mission 79 never loading the next room after meeting Xigbar in Halloween Town. The game crashed while creating the Detonator enemy. The whole mission, including the save afterwards, was played through on real hardware.
- Modified copies of the European dump are now accepted: an undub that restores the Japanese voices and cutscenes, a fan translation, or any other edit that keeps the gamecode `YKGP`. The first boot with one shows a notice that the ROM is modified, then the game runs from it.
- Dumps rebuilt by tools such as `ndstool`, which can be smaller or larger than the original 256 MiB, are supported.

## Technical notes

- **Detonator (`ov202`):** `Ov202_Construct` called `Ov107_PackTextureHandle` without its offset argument. On the DS that register is always `0` at the call. On the Vita it held a leftover value, so the body model was looked up in an unrelated resource and `Archive_GetMember` faulted. The call now passes `0` explicitly, and the function is declared with both arguments. No other call to this function was missing the argument.
- **ROM check:** the SHA-1 is no longer required to match. A dump is accepted when its gamecode is `YKGP`, its size is between 1 MiB and 512 MiB and the header's ARM9, ARM7, FNT, FAT and overlay tables lie inside the file. The verdict (unmodified or modified) is stored in `ux0:data/khdays/rom.verified`, so the hash runs only on the first boot with a given file. Stamps written by earlier versions remain valid.
- Cartridge reads, the read cache and the hash use the file's real size.
- Game code still comes from the decompilation, and every file is located through the dump's own file tables. A modification can therefore change only the game's data. Whether replaced files behave as the European ones did depends on the modification itself, for example on how its sound archive is laid out.
- Dumps of other regions (US `YKGE`, Japan `YKGJ`) are still rejected.

## Validation

- The native Vita build completed without warnings in the changed files.
- The fixed `Ov202_Construct` was compared with the original ARM9 overlay from the cartridge, and the rebuilt code now passes `0` exactly as the DS does.
- Mission 79 was played on real Vita hardware with the fixed build, from the Xigbar meeting through the next rooms, mission completion and save, with no faults in the log.
- An unmodified European dump passes the new header validation and is reported as unmodified.
- The undub path has not yet been tested with an actual undub dump on hardware. Reports are welcome, ideally with `ux0:data/khdays/log.txt` attached.

## Requirements

- A PS Vita running HENkaku/Enso with VitaShell.
- `libshacccg.suprx` installed in `ur0:data/`.
- The user's own European Kingdom Hearts 358/2 Days cartridge dump (`YKGP`), unmodified or modified, at `ux0:data/khdays/days.nds`.
- `kubridge.skprx` is optional and only used for enhanced crash reports.

No copyrighted game data is included in this release.
