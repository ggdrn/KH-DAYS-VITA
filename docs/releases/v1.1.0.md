# 1.1.0 — Release

Version 1.1 focuses on widescreen HUD correctness, stable scripted-camera rendering and an expanded dual-wield option for Roxas.

## Highlights

- Enabled Roxas's Oathkeeper and Oblivion dual-wield form in Story Mode mission replays and Challenges when Zero Gear and three Ability Units are equipped. The option is applied automatically and uses the existing Mission Mode player implementation.
- Fixed `LOCKED ON` and portal countdown text being clipped in the DETAIL single-screen layout.
- Fixed shortcut-command graphics becoming corrupted when holding L with the widescreen 4:3 HUD below 100% size.
- Fixed black flashes during cutscenes when the script changed cameras.
- Fixed the oversized duplicate Genie seen during Mission 24 dialogue camera changes.
- Fixed moving seams between repeating skybox polygons, including the Twilight Town sky.
- Improved stability for affected scripted scenes by presenting their authored 30 Hz frames directly instead of interpolating unrelated camera states.

## Technical notes

- Scripted field scenes and one-screen dialogue scenes bypass 60 Hz geometry interpolation while gameplay continues to use it.
- The DETAIL compositor now extracts the complete lock-on/countdown strip before masking the original DS HUD region.
- Widescreen shortcut composition remains synchronous while L is held and for four settling frames after release when HUD scaling is active.
- Opaque repeating textures use DS-compatible wrap detection at exact texture-period boundaries; translucent and cut-out effects keep the existing clamp behavior.
- The Story/Challenge player selector reuses the game's panel recipe evaluation and promotes Roxas to player group `0x13` only when the Zero Gear dual-wield combination is active.

## Validation

- Native Vita build completed successfully.
- The linked-ELF post-credits scene validation passed.
- Video composition and ending-link host tests passed.
- The final VPK archive passed integrity validation.
- The fixes were exercised on real Vita hardware during development. Additional mission-by-mission coverage is still welcome, especially for Story/Challenge dual wield and uncommon scripted scenes.

## Requirements

- A PS Vita running HENkaku/Enso with VitaShell.
- `libshacccg.suprx` installed in `ur0:data/`.
- The user's own European Kingdom Hearts 358/2 Days cartridge dump (`YKGP`) at `ux0:data/khdays/days.nds`.
- `kubridge.skprx` is optional and only used for enhanced crash reports.

No copyrighted game data is included in this release.
